# HOPE v2.0

A peaceful digital sanctuary for people going through difficult seasons.

## Features
- Rotating welcome messages & prominent headline
- Interactive “How are you feeling today?” section
- Letters to your future self (save + open date)
- “You are not alone” community stories with filters
- Save & copy reminders
- Share your story (name = letters only, age = numbers only)
- Dark / warm theme toggle
- Mobile menu with backdrop (tap outside to close)
- Gentle loading animation & scroll effects
- Pure HTML, CSS & JavaScript

## How to use
1. Open `index.html` with Live Server or any browser
2. Click **Edit** on the personal note to add your name
3. Upload the folder to GitHub Pages to make it live
